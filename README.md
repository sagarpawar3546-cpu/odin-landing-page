# Odin Landing Page

This project is part of The Odin Project Foundations curriculum.

## Description
This is a simple landing page built using **HTML and CSS** as a practice project to understand page structure, layout, and Flexbox.

The design is based on a provided template from The Odin Project and focuses on building sections step by step using semantic HTML and CSS Flexbox.

## What I Learned
- Structuring a webpage using semantic HTML
- Using CSS Flexbox for layout and alignment
- Styling sections like hero, information, quote, and footer
- Organizing a project with proper file structure
- Using Git and GitHub (add, commit, push)

## Notes
- This project is **not responsive**.
- Responsiveness was intentionally skipped as the goal of this assignment was to focus on **Flexbox and layout basics**.
- Mobile and tablet responsiveness will be covered in later lessons.

## Technologies Used
- HTML5
- CSS3 (Flexbox)
- Git & GitHub
